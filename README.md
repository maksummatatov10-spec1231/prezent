# prezent — презентации для PowerPoint 2010

В репозитории две готовые презентации (16:9, совместимы с PowerPoint 2010
и новее, валидны против ISO/IEC 29500):

## 📄 Kosta_Hetagurov.pptx — «Коста Хетагуров: поэт и художник»

15 слайдов-биографии с пояснительным текстом: настоящие фотографии и
картины Коста в хорошем качестве (репродукции из Викимедии/музейных
источников), без zoom-эффектов — вместо них мягкие появления и **много
переходов-«перелистываний»** между слайдами (fade, push, wipe, cover,
split, strips, comb, wedge …).

Слайды: титул с эскизным портретом • фотопортрет • аул Нар (арт-объект
в горах) • село Нар и дом-музей • учёба (Владикавказ → Ставрополь →
Академия художеств) • «Ирон фæндыр» • галерея из шести подлинных картин:
«К источнику», «Дети-каменщики», «Столовая гора», «Природный мост»,
«Скорбящий ангел», «Автопортрет» • памятник во Владикавказе • Осетинская
горка и церковь — последний приют поэта • финал «Весь мир — мой храм».

Генератор: `build_kosta.py`, изображения: `assets_kosta/`.

## 📄 Kosmos_Solnechnaya_sistema.pptx — «Космос: путешествие по Солнечной системе»

11 широкоэкранных слайдов с фото-фонами, полупрозрачными панелями,
~60 анимаций объектов и переходами между слайдами.

## Файлы презентаций

📄 **`Kosta_Hetagurov.pptx`** и **`Kosmos_Solnechnaya_sistema.pptx`** —
скачайте и откройте в PowerPoint.

Как посмотреть:
1. Нажмите кнопку **Download** у файла `Kosmos_Solnechnaya_sistema.pptx` на GitHub.
2. Откройте файл в PowerPoint 2010.
3. Нажмите **F5** — начнётся показ с анимациями.
4. Кликайте мышью (или стрелкой →), чтобы раскрывать пункты по клику;
   часть анимаций запускается автоматически при входе на слайд.

## Структура репозитория

- `Kosta_Hetagurov.pptx`, `Kosmos_Solnechnaya_sistema.pptx` — презентации;
- `build_kosta.py` — генератор презентации о Коста;
- `build_deck.py` — генератор презентации о космосе (python-pptx + «живой»
  XML анимаций `p:timing` / `p:transition`);
- `validate.py` — проверки целостности файла;
- `assets/` — фоны космоса (сгенерированы);
- `assets_kosta/` — фотографии и репродукции к презентации о Коста.

## Пересборка

```bash
python3 -m venv .venv
.venv/bin/pip install python-pptx Pillow lxml
.venv/bin/python build_deck.py     # соберёт «Космос» .pptx
.venv/bin/python build_kosta.py    # соберёт «Коста Хетагуров» .pptx
.venv/bin/python validate.py       # проверит ссылки анимаций и id
```

Все слайды проходят валидацию против официальной схемы ISO/IEC 29500
(PresentationML, transitional) — файл открывается в PowerPoint без
восстановления и предупреждений.
