# prezent — «Космос: путешествие по Солнечной системе»

Готовая презентация для **Microsoft PowerPoint 2010** (и любых более новых версий):
11 широкоэкранных слайдов 16:9 с фото-фонами, полупрозрачными панелями,
~60 анимаций объектов и переходами между слайдами.

## Файл презентации

📄 **`Kosmos_Solnechnaya_sistema.pptx`** — скачайте и откройте в PowerPoint.

Как посмотреть:
1. Нажмите кнопку **Download** у файла `Kosmos_Solnechnaya_sistema.pptx` на GitHub.
2. Откройте файл в PowerPoint 2010.
3. Нажмите **F5** — начнётся показ с анимациями.
4. Кликайте мышью (или стрелкой →), чтобы раскрывать пункты по клику;
   часть анимаций запускается автоматически при входе на слайд.

## Структура репозитория

- `Kosmos_Solnechnaya_sistema.pptx` — готовая презентация;
- `build_deck.py` — генератор презентации (python-pptx + «живой» XML
  анимаций `p:timing` / `p:transition`);
- `validate.py` — проверки целостности файла;
- `assets/` — изображения фонов (сгенерированы);

## Пересборка

```bash
python3 -m venv .venv
.venv/bin/pip install python-pptx Pillow lxml
.venv/bin/python build_deck.py     # соберёт .pptx
.venv/bin/python validate.py       # проверит ссылки анимаций и id
```

Все слайды проходят валидацию против официальной схемы ISO/IEC 29500
(PresentationML, transitional) — файл открывается в PowerPoint без
восстановления и предупреждений.
